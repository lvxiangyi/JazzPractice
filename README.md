# Cadence · 钢琴练习室

本地 HTML 原型。导入 MusicXML 乐谱，通过 Web MIDI 连接电钢琴，进行等音或跟拍练习。乐谱和演奏数据仅在当前浏览器内处理，无需账户，没有上传服务。

## 启动

已安装 Node.js 时，在项目目录执行：

```powershell
npm start
```

在 Chrome 或 Edge 打开 **http://localhost:5173**。也可以双击 `start-demo.cmd`，保持启动窗口运行。按 Ctrl+C 停止服务。

运行所需的乐谱引擎已随项目放入 `vendor/`，启动 demo 不需要 npm install，也不依赖外部 CDN。建议使用本地 HTTP 服务打开，而不是双击 HTML，以便浏览器正常授权 MIDI。

## 使用

1. 点击右上角「连接电钢琴」，允许浏览器访问 MIDI。成功后显示实际设备名称；弹下琴键可以查看音名和力度。物理连接不代表浏览器已经授权。
2. 谱面上方的下拉框列出 `sheet/` 目录中的全部 MusicXML（`.musicxml` / `.xml` / `.mxl`），放入新文件后刷新页面即可出现。页面默认载入 `sheet/Waltz_for_Debby_bars_1-40.musicxml`（Waltz for Debby，第 1–40 小节），后续开发与主体验验证均以此谱为参考。可导入 / 拖入其他 `.musicxml`、`.xml`、`.mxl`，再点击「Waltz for Debby · 参考谱」切回。参考文件不会被改写。
3. 默认使用跟拍模式，可切换为等音模式，并选择双手、右手或左手。练习设置中的「节拍器音量」控制预备拍和练习节拍提示音，0% 为静音；音量在刷新后保留。
4. 点击「开始练习」。等音模式等待当前音组全部命中，错音不会推进；跟拍模式先按当前拍号预备，再按 BPM 前进；预备长度可在侧栏「跟拍前预备」旁选择 1 小节（默认）或 2 小节，取消勾选则不预备，选择在刷新后保留。预备每拍响一下、每小节第一拍加重：4/4 每小节四下，3/4 三下四分音符，6/8 六下八分音符；BPM 以四分音符计。预备期间不判分。预备的最后一小节就是起始音所在的小节（与 iReal Pro / MuseScore 相同）：从小节第一拍开始时数完整小节后进入；弱起（第一小节短于拍号）或从小节中间开始时，起始音在预备小节内自己的拍点进入，预备拍继续响到小节线（如 4/4 的一拍弱起：1 2 3 4，弱起音与第 4 下同时进入，下一小节为第 1 小节；从第 3 拍开始则 1 2 后进入，3 4 照常响）。练习中的节拍器重音与伴奏鼓型同样按弱起对齐；伴奏不在弱起小节演奏，从第 1 小节的强拍进入。
5. 选择跟拍容差：可一键选宽松 ±200 ms（默认）、标准 ±120 ms、严格 ±80 ms，也可拖动滑块在 ±40–400 ms 之间以 10 ms 为步长自由设定（下拉框显示「自定义」；选了「自定义」后保持不变，直到再选预设），设定保存在本机，改动后从当前选段重新开始。窗口内按距离最近的同音高起音匹配；80 ms 以内（容差小于 80 ms 时为整个容差）为准时，其他命中显示偏早 / 偏晚。窗口之外按错音处理，未命中的谱面音在窗口结束后记为漏音。
6. 谱面绿色音符为准时命中（等音模式为音高命中），金色为容差内偏早 / 偏晚，红色为漏音；额外错音以红点和文字反馈显示。
7. 在谱面上方选择起止小节并勾选「循环」，可反复练习选段；成绩按轮累计，每轮清除音符颜色。取消循环后，当前轮结束时显示结果。暂停可中断循环。
8. 点击谱面音符可定位并重新开始一次练习；可随时调速、暂停或回到选段开头。试听遵循选段和循环设置，不计分。
9. 点击播放栏的「♩ 节拍器」打开专门设置界面，可选择跟弹 / 试听时是否开启，并逐拍选择发声位置。3/4 可只选第 1 拍、只选第 3 拍或任意组合；每种拍号的选择与开关会保存。预备拍按所选小节数完整提示（与节拍器开关和发声拍点无关），音量与侧栏同步。
10. 测评式回看（参考 Piano Marvel）：练习进行中谱面不显示你弹的音（可在谱面上方勾选「演奏中显示我弹的音」改为实时显示）；暂停或结束后：弹对的谱面音符不再另画一个音符，而是直接把原谱音符染成绿色（准时）或金色（偏早 / 偏晚）；弹错的音（音高不对，或音高对但超出节奏窗口）在它所属的谱面位置画成红色音符（按你实际弹的音高；与原谱音符同一行或相邻一行时向右错开约一个符头），伴奏 / 不计分的音为蓝色，同样对齐到该位置的符头，不标音名，由你自己读谱；Level 1–3 生成的左手和弦音、导向音在谱面上没有音符，弹对时画在对应位置的符头处（左手在低音谱表），绿色或金色；Level 模式下没弹对的音按角色分手：与当前和弦的左手排列或 3 / 5 / 7 / 9 音同音级（任意八度、且不是旋律的音级）、低于中央 C、或比旋律低一个八度以上的，算左手画在低音谱表，紧挨旋律或在旋律之上的算右手；升降号按谱面同音高音符或调号拼写。侧栏「演奏回顾」逐个位置列出「谱上写的音 → 你弹的音」。采用中央 C = C4（MIDI 60）的命名方式。 中途暂停也会立即显示已弹的音，继续练习时再隐藏。左手（Lead Sheet 左手目标、伴奏音、以及中央 C 以下的音）画在低音谱表上：双谱表乐谱用原有低音谱表；只有旋律的谱会在每行歌词下方加一行低音谱表（仅用于回看，不改原谱；为此这类谱的行距会加大）。Level 1–3 中，弹错的左手音为红色实心音符，应弹而漏掉的生成目标音（左手和弦音、导向音）为红色空心音符，画在应弹位置略左侧。
11. 「演奏诊断」把每次起音分为命中、超出节奏窗口、音高不符 / 多弹、伴奏四类，统计起音偏差的中位数与离散度（IQR），并给出主要原因：稳定的整体偏晚提示固定延迟，分散的偏差提示节奏不稳，音高不符比例高则是弹错音。「伴奏音不计错」在只有旋律的谱（如参考谱）上默认开启：低于当前旋律小三度以上、且不是谱面目标的额外音按伴奏处理。「延迟校准」用音频时钟播放 4 + 8 下咔嗒声，测出声音输出 + MIDI 输入 + 反应的固定延迟，可一键应用为跟拍补偿（保存在本机）。消息按系统接收时间戳判定。
12. 节拍器基础音量已增强，滑块范围扩为 0–200%，侧栏与专门面板同步。

屏幕琴键也可点击。电脑键盘 A S D F G H J K 对应 C4 D4 E4 F4 G4 A4 B4 C5，W E T Y U 对应黑键。空格开始 / 暂停（输入控件和按钮获得焦点时保留其原有键盘行为）。

## 全屏、Lead Sheet 与 Swing

- 点击谱面上方「全屏练习」，默认收起侧栏、标题和次要工具栏，几乎整屏用于乐谱。用滑块或 ＋ / − 在 70%–350% 间调整谱面。谱面工具栏的「每行」可选 4 小节、8 小节（默认）或按原谱换行，选择会保存。再次点击或按 Esc 退出。浏览器禁止原生全屏时使用页面内全屏。全屏 / 缩放会暂停练习，保留位置与统计。
- 「自由布局」中可以展开 / 隐藏侧栏、精简工具栏、显示 / 隐藏屏幕琴键，调整侧栏宽度（200–440 px）和非全屏谱面区域高度（500–1400 px）。桌面端可拖动谱面和侧栏之间的分隔条，也可用方向键调整。全屏和普通模式的侧栏、精简显示偏好分别保存；缩放、布局和跟随选项保存在当前浏览器，刷新后保留。窄屏全屏下，展开的侧栏作为浮层显示。
- 「演奏位置线」控制绿色竖线显示；「自动跟随」独立控制谱面滚动，可选居中滚动（默认）、逐行翻谱（参考 Piano Marvel：每进入新的一行，就把这一行平滑移到视窗顶部，下方后续各行保持可见）、滚动跟随或翻页跟随。居中滚动让正在读的那一行始终停在谱面区域的垂直中央（只有旋律的谱以旋律行与回看用低音谱表的整体中心为准），在每行最后约 30% 处（跟拍 / 试听按拍点，等音模式按已弹的音符）连续地滑向下一行，不会整页跳动；暂停时只在位置改变时定位一次，手动滚动不会被拉回。旧版本保存的跟随方式会一次性切换为居中滚动，之后的选择照常保存。等音模式在当前目标弹对后移到下一位置；跟拍 / 试听时在同一谱行内按拍点插值移动，换行时跳到下一行。到达视窗边缘后自动滚动或翻页，让当前谱行保持可见。关闭自动跟随后可自由浏览其他小节。
- **展开反复**（谱面上方勾选，视奏用）：把反复记号和一房 / 二房（含 "1, 2" 这类多遍房子与 times 次数）按演奏顺序展开成一条直线，不用往回跳：例如 All of Me 显示为 1–16、1–8、17–24 共 32 小节。只改内存中的副本，不改 `sheet/` 里的文件；重复出现的小节去掉多余的调号 / 拍号 / 谱号和原谱换行，保留真正的变化，反复线改为普通小节线，终止线只留在最后。音符、和弦、节拍位置、弱起与预备拍、Level 1–3 与伴奏都与不展开时的演奏顺序一致；小节名称（谱面上方的小节号、练习段落下拉框、位置标签、演奏回顾与漏音提示）统一按原谱印刷的小节号，重复的一遍写作「第 9 小节（第 2 遍）」；不展开时同样按印刷小节号，弱起小节显示为「弱起小节」。D.C. / D.S. / Coda / Fine 不展开（载入时会提示）。伴奏的段落仍按原谱的反复记号划分：段落起点的每一遍都算段落起点，所以人性化 / 2-feel 伴奏与不展开时完全相同。勾选状态会保存，切换时保留当前乐谱。
- 「检测规则」可选原谱、Level 1、Level 2、Level 3。切换只生成新的检测目标，不修改源 MusicXML、不加写音符、不改和弦符号。新增的左手 / 右手导向音要求显示在谱面上方的提示栏，不画进原谱；试听仍是原谱音符。
- **八度判定**：严格（按提示的实际音高）、左手忽略八度（左手 3 / 7 等目标任意八度均算对，双谱表乐谱的低音谱表同样适用）、全部忽略八度（旋律也可移八度）。优先匹配原八度；回看中音符画在你实际弹的八度。选择会保存。
- **Level 1**：左手在每次和弦标记处弹 3、7；右手按原谱旋律。
- **Level 2**：左手改为 3、5、7、9，在 C2–B3 范围内选择跨度不超过八度的排列，按与上一和弦对应声部的总半音移动最小来选择。按提示的实际音高检测，不是任意八度均可。右手旋律不变。
- **Level 3**：左手同 Level 2；右手在骨干音处，除原旋律外再加一个当前和弦的 3 或 7 音。默认骨干音是每次和弦出现后的首个旋律起音；也可选强拍或每个旋律音。强拍近似取 4/4 的第 1、3 拍，其他单拍子的第 1 拍，6/8 等复合拍每组三个八分音符的起点；这不是完整的乐句骨干分析。
- 额外导向音须在旋律下方八度内、已生成左手排列的上方，且与旋律不是同一音级。旋律本身是 3 或 7 时，需另外弹另一个导向音。程序会为 Level 3 调整左手排列以留出空间。MIDI 无法识别实际使用哪只手，左右手按这些目标音域和角色判定。
- 左手只在换和弦（含重复写出的同名和弦）处要求新起音，后续旋律音不要求每次重弹左手；可选左手或右手单独练习。从和弦中途定位 / 开始循环时，会在起点补要求一次左手和弦。当前原型按音组收集命中，不评估手型或同时按下程度。
- 和弦从第一乐器声部的 MusicXML `<harmony>` 读取，支持根音升降、常见大 / 小 / 属 / 减 / 半减 / 增七和弦及 9/11/13 扩展和 `<degree>` 升降 / 省略。六和弦（6、m6）没有七音，以 6 音代替 7 音作为导向音（Level 1 左手弹 3、6）。大、小、减、增三和弦分别按 maj7、m7、dim7、augMaj7 规则补七音，默认加自然九音；显式的升降度数优先。这是本练习约定，不代表所有爵士语境的唯一配法。slash bass 不强制加入，因为此处按无根排列训练。
- 挂留、数字和弦、微分音、缺少所需度数等无法明确套用规则的情形会提示并保留上一检测规则，不静默猜测。`N.C.` 保持旋律但不要求新增和弦音。含多声部旋律时取第一谱表当前最高起音；请优先导入单旋律 Lead Sheet。
- 没有和弦标记的谱子不能启用 Lead Sheet 检测。可点击「载入 Lead Sheet 示例」试用附带的 ii–V–I 示例，或导入自己的带和弦标记的乐谱。此按钮是显式换曲，单纯切换等级不换曲。
- **Swing**：可切换直八分与 2:1。只将成对八分音符的后半拍起音从 1/2 拍移至 2/3 拍，同时调整跟拍检测、指示线推进和原谱试听时值；谱面不变。三连音、含十六分细分的拍和 6/8 等复合拍保持原节奏。第一版是固定 2:1 练习模型，未实现随速度变化的 swing 比例。等音模式仍不限制起音时间；节奏训练请用跟拍模式。

练习顺序参考：[Berklee 三音、七音与旋律内声部](https://www.berklee.edu/berklee-today/fall-2003/contrapuntal-improvisation)、[Berklee 钢琴排列与声部连接](https://online.berklee.edu/takenote/basic-piano-voicing-techniques/)。上述三级是本产品的训练分级，不是统一的学院课程标准。

## 伴奏（Medium Swing）

- 侧栏「伴奏 · Medium Swing」：勾选后，跟拍练习与试听时按谱面和弦符号自动生成走动贝斯与刷子鼓；等音模式不播放。可分别开关贝斯 / 鼓，音量 0–150%，设置会保存。
- 「律动」可选 **简单**（原规则）/ **人性化**（默认）/ **人性化 · 开头 2-feel**，选择会保存，切换后立即重新编排。同一轮（同一随机种子、同一速度与选段）生成的伴奏完全相同，下一轮换一种变化。
- 简单：4/4 按根音 – 3 – 5 – 经过音，每个小节线与换和弦前用半音或下一和弦的五音引入；3/4（爵士华尔兹）按根音 – 5 – 经过音；鼓为固定的 swing ride（附点在三连音第三个八分音位置）、2、4 拍踩镲、轻柔底鼓与偶尔的刷子点缀。
- 人性化 · 贝斯：
  - 目标导向：每个小节（或同一和弦的半小节）先确定下一个强拍要落的音（下一和弦的低音 / 根音，slash 和弦按斜线后的低音），八度保持在 E1–E3（MIDI 28–52）并向中间音区靠拢，再填中间的拍；每次换和弦的强拍必为该和弦低音。
  - 音型库按权重随机，相邻小节不重复同一音型：和弦琶音（R-3-5-7 / R-3-5-3）、按和弦性质推出的音阶级进（R-2-3-5 或下行 R-7-6-5）、半音引入（第 4 拍为目标音 ±1）、属音引入（第 4 拍为目标的五音）、包围（第 3、4 拍从上 / 下包住目标）、偶尔的八度跳。3/4 用 R-5-引入、R-3-引入、R-音阶-引入；两拍的和弦为 根音-引入。不出现同音连续重复，除八度跳外跳进不超过大六度。
  - 力度与时值：第 1、3 拍较重（约 1.0），2、4 拍较轻（约 0.85），各有 ±8% 的随机；音长为一拍的 85–95%，引入音约 75%。
  - 微小时值：贝斯整体略微靠前（平均约 −6 ms，±5 ms 抖动），所有偏移不超过 ±25 ms。
  - 装饰：约 8% 的小节在最后一拍的三连音末位加一个轻声「跳音」（目标音的半音邻音），前一音相应缩短，不会叠音。
  - 结尾：选段最后一个和弦的根音保持到小节末。
  - 2-feel（可选）：第一个段落（到第一个段落标记为止，没有标记则前 8 小节）每小节两个二分音符（第 1 拍根音，第 3 拍五音或引入音；3/4 为附点二分根音），之后进入走动。
- 人性化 · 鼓（刷子）：
  - Swing 比例随速度变化：90 BPM 及以下附点约在 0.68 拍，速度越快越平直，220 BPM 约 0.60（简单模式保持 2/3）。
  - Ride 每个音力度 ±10%、时值 ±5 ms 随机；约 10% 的小节省去一个附点，约 8% 的小节在第 1 或第 3 拍多加一个附点。踩镲仍在 2、4 拍（3/4 为 2、3 拍），底鼓每拍极轻地「羽毛踩」。
  - 乐句：从选段开头按演奏顺序每 4 小节为一句（弱起不计，遇到段落重新计数）。刷子点缀在句首很少、越接近第 4 小节越多；每句最后一小节在最后一拍的三连音上加 2–3 下短加花；8 小节句尾或段落结尾在最后两拍加力度渐强的三连音加花，下一小节强拍用重音镲 + 底鼓收住；段落开头偶尔有刷子扫。
  - 段落从 MusicXML 读取：排练记号（rehearsal）、双纵线 / 终止线、反复记号；第二房子（及以后的反复结尾）不算新段落，它在演奏顺序里替代第一房子的位置继续计句；没有标记时按每 8 小节划分。例如 Waltz for Debby 在第 17、33 小节（A2、B）分段。
- 伴奏在预备拍期间预先排程，与练习时钟同步；暂停立即停止，循环和选段沿用。音色来自 FluidR3_GM（MIT 许可，见 `vendor/accompaniment/LICENSE.txt`），约 1.2 MB，离线可用。
- 后续计划：导入 iReal Pro `irealb://` 链接（只有和弦与曲式，无旋律）、Bossa / Ballad / Waltz 等风格。

## 原型范围

- 通过 OpenSheetMusicDisplay 排版真实乐谱。位置线根据目标音组和当前计时前进，并非音频录音识别或跳奏后的自动定位。
- 支持 MusicXML score-partwise、双谱表、和弦、休止、附点与连音时值；反复遍历沿用乐谱引擎。装饰音显示但不判分，延音线后续音不要求重新按键。
- 练习声部分离以第一 / 第二谱表为依据，主要面向单钢琴乐谱；多乐器总谱建议先导出钢琴声部。
- 评分统计音高命中 / 错音 / 漏音与起音时间偏差。跟拍匹配可以跨音组边界，按最近的未命中同音高起音分配；每次按键只计入一个音。暂不评估按键时长、踏板、力度和表情，也不自动识别跳奏后的位置。时间偏差按浏览器收到输入时计算，未做设备延迟校准。
- 小节选段取首次连续经过该区间的部分；全曲保留乐谱引擎的反复遍历（勾选「展开反复」后按展开后的小节选段）。点击反复段中的音符定位至其首次出现的位置。
- 当前 BPM 统一覆盖全曲，范围 30–200；不跟随谱面中途变速。等音模式的非休止音可以停留任意时间，和弦按当前音组收集命中。
- 试听使用浏览器合成音色。MIDI 输入不回放音频，以免与电钢琴自身声音重复。
- 支持 MIDI 热插拔、note-on / note-off、零力度 note-on。多个已连接 MIDI 输入都会接收；仅有音频线的连接无法提供 MIDI 音符。
- 切换模式、声部、容差、选段、点击音符或导入新曲会重置练习成绩；缩放、调整窗口或改变谱面布局会暂停并清除反馈圆点，但保留音符颜色和统计。刷新后载入默认参考谱，不保留演奏成绩；布局偏好保留。
- 导入限 10 MB / 20,000 个音符。真实电钢琴通信仍需在用户设备的浏览器中验证。
